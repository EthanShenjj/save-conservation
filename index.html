工作模式

两种模式，覆盖沉淀与回顾

一个关键词触发，无需复杂配置。保存模式归档对话，统计模式回顾知识库全貌。

📥

保存模式 · Save Mode

save · 保存对话 · 记录这次对话 · remember this

将当前对话重建成结构化 Markdown 记忆文档，自动判断归属范围，写入对应项目目录，并执行知识库 ingest 流程。

  • 读取已配置的 storage_root
  • 判断全局记忆 or 项目记忆
  • 调用脚本获取正确的 raw 路径
  • 写入结构化 Markdown 文档
  • 同日追加增量内容，避免碎片文件
  • 执行目标知识库 ingest 流程
📊

统计模式 · Stats Mode

统计看板 · 内容统计 · 记忆统计 · 项目统计

扫描已保存的 raw 记忆文档，生成多维统计看板，帮你回顾知识库全貌，发现高频主题和需要复盘的项目。

  • 项目数、记忆文档数、全局文档数
  • 项目分布与讨论热度排名
  • 同日增量次数统计
  • 最近 7/30 天更新趋势
  • 高频主题自动提取
  • 智能回顾建议
核心能力

六大能力，构建轻量 LLM Wiki

AI 负责理解、摘要和知识提取，脚本负责确定性文件系统操作。职责分离，稳定可靠。

🏗️

结构化重建

将对话重建成包含元数据、概要、用户意图、关键行动、关键产出、用户反馈的结构化 Markdown 文档，不是简单粘贴。

📂

智能路由

自动判断对话属于全局知识还是项目记忆，全局保存到 raw/general/，项目保存到 raw/{project}/。

🔁

同日增量

同一项目同一天的后续对话自动追加为增量更新块，而不是创建碎片文件。保持上下文连贯，减少文件膨胀。

🏷️

元数据提取

自动提取日期、平台、主题、范围、标签等 YAML frontmatter，便于后续检索和统计。

📊

统计看板

一键生成知识库统计 Markdown 报告：项目分布、讨论热度、高频主题、近期更新、回顾建议。

🔗

Ingest 集成

保存后自动执行目标知识库的 ingest 流程：实体、概念、洞察、索引、日志、持久化记忆，无缝衔接。

工作流

Save 模式八步流程

从读取配置到 ingest 完成，全流程透明可控。

1
读取配置

运行 config show 读取已配置的 storage_root。若配置缺失，引导用户初始化。

2
判断模式

根据用户输入判断是 Save 模式还是 Stats 模式，走不同分支。

3
确定范围与项目名

判断 general 或 project。项目名优先级：用户指定 > Git 仓库名 > 工作区名 > 当前目录名。

4
获取目标路径

调用 target 命令获取 mode（create/append）和 target_path。

5
重建对话记录

按模板将对话重建为结构化 Markdown：元数据、概要、意图、Q/A 摘要、行动、产出、反馈。

6
写入或追加

mode=create 时新建 raw 文件；mode=append 时通过 append 命令追加增量块。

7
执行 Ingest

按目标知识库的 CLAUDE.md 执行 ingest：sources、entities、concepts、insights、index、log、memory。

8
汇报结果

报告 raw 路径、ingest 更新内容、持久化记忆变更，完成保存。

存储结构

清晰的二级目录组织

所有 raw 记忆文件按项目归档，文件名包含日期和简短标题，便于检索和排序。

storage_root/ ├── raw/ │ ├── general/ # 全局知识 │ │ ├── 2026-07-13-react-patterns.md │ │ └── 2026-07-14-writing-tips.md │ ├── my-app/ # 项目记忆 │ │ ├── 2026-07-13-auth-refactor.md │ │ └── 2026-07-13-api-design.md # 同日增量 │ └── data-pipeline/ │ └── 2026-07-14-etl-optimization.md ├── wiki/ # 知识库页面 │ ├── index.md │ ├── log.md │ └── entities/ ├── memory/ # 持久化记忆 └── config.json # 配置文件

存储规则

🌍
全局知识 → raw/general/

跨项目通用知识、个人偏好、工作风格等

📦
项目记忆 → raw/{project}/

特定仓库、产品、功能、调试会话等

🔁
同日增量追加

同项目同日已有文档时，追加增量块而非新建文件

⚠️
不写根目录

raw 文件不直接写到 raw/ 根目录，必须归入二级目录

辅助脚本

memory_store.py 四大命令

确定性文件系统逻辑封装在 Python 脚本中，AI 只负责摘要和知识提取，职责清晰。

memory_store.py — 命令一览 
# 1. 配置管理：读取或初始化 storage_root
python scripts/memory_store.py config show
python scripts/memory_store.py config init --storage-root /path/to/kb

# 2. 目标路由：计算 raw 路径，判断新建或同日追加
python scripts/memory_store.py target \
  --storage-root /path/to/kb \
  --scope project \
  --project-name my-project \
  --title "demo" \
  --date 2026-07-13

# 3. 增量追加：将准备好的 Markdown 追加到已有 raw 文档
python scripts/memory_store.py append \
  --target /path/to/raw.md \
  --content-file /tmp/increment.md

# 4. 统计看板：扫描 raw/ 并输出 Markdown 统计报告
python scripts/memory_store.py stats --storage-root /path/to/kb
快速开始

三步上手

克隆仓库、配置路径、开始保存。零外部依赖，纯 Python 标准库实现。

① 克隆安装

将仓库克隆到 Codex skills 目录

bash 
git clone https://github.com/EthanShenjj/save-conservation.git \
  ~/.codex/skills/save-conversation

② 配置存储路径

设置你的知识库根目录

bash 
python scripts/memory_store.py config init \
  --storage-root ~/my-knowledge-base

③ 开始使用

在 Codex / Claude Code 中输入关键词即可触发

save → 保存当前对话
统计看板 → 生成统计报告
